# Truck

Tamiya Racing Truck ([TT01 type E Chassis](https://tamiya.com/english/products/product_info_ex.html?genre_item=e_0102))  
Kit wheels/tyres (Inserts can be used)  
Motors – Saturn 20T / Core 21T / kit supplied torque tuned 25T (brushed)  
19 tooth pinion
2S Lipo

Permitted hop ups:

- Full bearing set (essential)
- Oil shock absorbers
- Alloy centre prop shaft
- Alloy motor mount
- Adjustable turnbuckles (steering only)
- Universal joints (not really necessary)

# Le Mans

Tamiya group C or Tamiya F1 chassis  
Hobbywing juststock 17.5 combo part number HW38020321  
Group C or F1 tyres  
LMP style bodyshell  
No reverse set on speedo
2S Lipo
